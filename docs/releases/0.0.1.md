# RAVET 0.0.1

The first source preview combines portable Rust audio processing, prepared
graphs, DSP, observable state, MIDI/OSC, audio-file workers and reusable UI
components with public plug-in, standalone, embedded and mobile references.
[RAVET Foundry](../foundry.md) creates independent consumer projects. The
[feature catalogue](../FEATURES.md) records each capability and its limits.

Workspace packages, public native reference versions, mobile fixtures and the
Arduino library identify this snapshot as 0.0.1. Independent project starters
retain their own initial product version. Cargo packages remain `publish = false`;
this preview is distributed as source, with no crates.io or binary release.

## Scope and licensing

Public APIs are provisional. Implemented features are usable only within their
documented bounds; prototype integrations retain their stated host/platform
validation limits. Local tests do not establish universal DAW/device support,
physical embedded/mobile compatibility or real-time deadlines. VST2 is excluded.

The source edition is GPL-3.0-only. The commercial agreement remains a draft,
and this preview does not grant proprietary distribution rights. Optional
codecs, font fixtures and other dependencies retain their separate notices and
obligations; see [LICENSING.md](../../LICENSING.md). External SDKs and proprietary
consumer projects are excluded from this repository.

## Publication boundary

The public repository contains only the cleaned history. The earlier private
repository, whose hosted copies retained pre-cleanup commits, stays private as
an archive. See the [publication guide](../publication.md).

Release validation receipts are recorded in [work status](../WORK_STATUS.md).
